# کافی نت آراد — کاتالوگ فیلم و سریال

این نسخه یک سایت کامل و آماده برای GitHub Pages است.

## فایل‌ها
- `index.html` — صفحه اصلی
- `styles.css` — طراحی کامل و واکنش‌گرا
- `assets/logo.svg` — لوگوی کافی نت آراد
- `assets/poster-1.svg` تا `poster-20.svg` — پوسترهای گرافیکی آماده
- قابلیت جستجو، فیلتر فیلم/سریال، مرتب‌سازی، نمایش جزئیات، انتخاب شانسی، علاقه‌مندی و حالت روشن/تیره

## انتشار روی GitHub Pages
همه فایل‌ها را در ریشه همان Repository قرار بده و در:
Settings → Pages
گزینه `Deploy from a branch` را روی `main` و `/ (root)` بگذار.

سپس آدرس GitHub Pages نمایش داده می‌شود.
